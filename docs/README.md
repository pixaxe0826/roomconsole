## 변경 이력

과거 패치별 설치 문서는 현재 통합 소스에서 제거했습니다. 기능 변경은 [CHANGELOG](../CHANGELOG.md), 현재 검증은 [TEST_REPORT](TEST_REPORT.md)에서 확인하세요. Git 이력을 사용하는 저장소에서는 이전 버전의 문서를 해당 tag/commit에서 확인할 수 있습니다.
