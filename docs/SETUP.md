# 설치와 업데이트

[문서 홈](../README.md) · [운영·백업](DEPLOYMENT.md)

## 1. 준비

서버에는 Python 3.11 이상이 필요합니다. 프런트엔드용 Node.js나 npm 설치는 필요 없습니다.
처음 Python 의존성을 내려받을 때 인터넷을 사용합니다. iPad는 서버와 통신 가능한 동일 LAN에서 Safari로 접속합니다.

새 저장소 작업 폴더는 운영 폴더와 분리하는 것을 권합니다. ZIP에는 기존 사용자의 DB·키·설정이 들어 있지 않습니다.

## 2. Windows 실행

프로젝트 루트에서 `START_WINDOWS.bat`를 실행합니다. 최초 설치가 도중에 실패했거나 Python Launcher(`py`)가 없다면:

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe run.py
```

가상환경이 이미 있다면 첫 줄은 생략할 수 있습니다. 설치 후 다른 PC로 `.venv`를 복사하지 말고 그 PC에서 다시 만드세요.
`run.py`의 서버 콘솔에 버전과 관리자 키가 표시됩니다. 이 콘솔을 종료하면 서버도 종료됩니다. 관리자 브라우저 탭만 닫는 것은 서버를 종료하지 않습니다.

```text
http://localhost:8088/manager
```

## 3. Linux / macOS

```bash
sh start.sh
```

또는 직접 실행:

```bash
python3 -m venv .venv
.venv/bin/python -m pip install -r requirements.txt
.venv/bin/python run.py
```

## 4. 설정 변수

| 변수 | 기본값 | 비고 |
|---|---|---|
| `HUB_HOST` | `0.0.0.0` | 직접 Python 실행의 바인딩 주소 |
| `HUB_PORT` | `8088` | 직접 실행 포트 또는 Compose의 호스트 포트 |
| `HUB_DATA_DIR` | 프로젝트 `data/` | DB·키·음원. 운영에서는 절대 경로 권장 |
| `HUB_WIDGET_DIR` | 프로젝트 `widgets/` | 신뢰한 위젯 폴더 |
| `HUB_ADMIN_TOKEN` | 무작위 생성·저장 | 직접 지정 시 최소 24자 |
| `HUB_INGEST_TOKEN` | 별도 무작위 생성·저장 | 관리자 키와 분리 |
| `HUB_SECURE_COOKIE` | `false` | 실제 HTTPS 환경에서만 `true` |

**직접 Python 실행은 `.env`를 자동으로 읽지 않습니다.** `.env.example`을 복사하는 것만으로 Python 실행 설정이 바뀌지 않습니다. Compose는 `.env`를 읽지만 제공된 YAML에 지정한 변수만 컨테이너에 전달합니다.

PowerShell 예시:

```powershell
$env:HUB_DATA_DIR = 'D:\RoomHubData'
$env:HUB_PORT = '8088'
.\.venv\Scripts\python.exe run.py
```

위 경로는 예시입니다. 기존 데이터가 다른 곳에 있으면 먼저 그 경로를 지정해야 합니다. 비어 있는 새 폴더를 지정하면 새 DB·키가 생성됩니다.

## 5. iPad 연결

관리자 **표시 기기 → 새 화면 연결**에서 실제 서버 IP를 포함한 주소로 링크/QR을 생성합니다. iPad에서 열면 10분·1회용 코드가 쿠키로 교환되고 주소에서 코드는 제거됩니다. iPad에서는 관리자 키를 입력하지 않습니다.

다음 접속부터는 같은 서버의 `/client`를 사용합니다. 표시 세션은 30일이며 자동 무기한 갱신은 구현하지 않았습니다. 만료·취소·쿠키 삭제 시 새 링크가 필요합니다. 관리자 세션은 12시간입니다.

화면만 열린 채 키보드로 편집하지 않도록 만들었습니다. 날짜 선택·위젯 확대·할 일 완료 체크는 가능합니다. 반복 작업의 완료는 해당 회차에만 적용됩니다.

## 6. 기존 0.1.1 설치와 통합 ZIP의 관계

**이 ZIP은 GitHub에 올릴 깨끗한 소스본이며 데이터 이전 패키지가 아닙니다.** 기존 미리보기 수정과 주간 이동·완료 기능이 이미 들어 있습니다. 0.1.1을 사용하고 있다면 기능 업데이트를 위해 운영 폴더를 바꿀 필요는 없습니다.

동일 PC에서 새 소스 폴더를 실행하려면:

1. 기존 서버를 정상 종료하고 `data/` 전체·사용자 위젯·환경 설정을 프로젝트 밖에 백업합니다.
2. 새 폴더에서 가상환경을 만들고 의존성을 설치합니다.
3. `HUB_DATA_DIR`을 기존 데이터의 절대 경로로 지정합니다. 또는 서버가 멈춘 상태에서 `data/` 전체를 새 위치로 복사합니다.
4. 새 소스가 같은 서버 주소·포트에서 실행되는지 확인합니다. 동시에 두 서버를 같은 DB로 운영하지 마세요.
5. 관리자와 iPad를 새로고침합니다. 주소·쿠키·DB 세션이 유지되고 유효하다면 재페어링이 필요하지 않습니다.

커스텀 `widgets/`를 통째로 삭제하거나 덮어쓰기 전에 별도로 비교하세요. 저장소에는 기본 위젯 다섯 개만 포함합니다. 이미 적용한 환경 설정과 키를 `.env.example` 값으로 덮어쓰지 마세요.

## 7. 연결 문제

| 증상 | 확인 |
|---|---|
| PC에서는 열리는데 iPad에서는 안 열림 | iPad 주소가 `localhost`인지, 사설망 방화벽·게스트 Wi-Fi 격리 여부 |
| 관리자 로그인 반복 실패 | 현재 서버 데이터 경로의 키인지, HTTP에서 secure cookie를 켰는지 |
| 할 일/설정이 비어 있음 | 기존과 다른 `HUB_DATA_DIR` 또는 Docker 볼륨을 사용하는지 |
| 서버 시작 때 포트 점유 오류 | 기존 Python 서버나 컨테이너가 이미 실행 중인지 |
| 업데이트 후 화면이 이전과 같음 | 관리자 강력 새로고침, iPad 페이지 새로고침 |
| 서버 끊김 이후 완료 저장 안 됨 | 오프라인 쓰기 큐는 구현하지 않았으므로 연결 복구 후 다시 조작 |

공유기의 DHCP 예약 등으로 서버 주소를 고정하면 편리합니다. 공개 인터넷에 포트를 열어 해결하지 마세요.
