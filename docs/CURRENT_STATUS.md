# 현재 상태 — Room Hub 0.1.6

사용자는 0.1.5 + STT 정확도 패치와 Qwen runtime의 실제 사용을 확인했습니다. 이번 0.1.6은 제작 환경 검사만 수행했습니다. 물리 V35/iPad/Qwen 품질·속도·온도·절전 동작은 확인하지 않았습니다.

## 보존하는 운영 조건

V35/Termux/PRoot roomhub, 메인8088, HTTPS8443, SSH8022, 기존 홈페이지8080, Qwen localhost8090. Whisper multilingual Base/ko/6T/careful(beam5), Qwen3-0.6B-Q5_K_M CPU6T/컨텍스트1024/non-thinking. 설정·가중치·엔진 바이너리·DB·토큰·인증서는 소스에 포함되지 않습니다.

## 구현된 0.1.6

공통 시계와 날짜 의미 검증, 구어체 조회의 DB 연결, 모델의 날짜/완료필터 왜곡 거부, 공통 읽기 서비스와 스냅샷, 허용 기능 등록부, 관리자 근거 표시, 일반 대화 샘플링·상한 분리와 응답 후 반복/에코/잘림 거부. 모든 비서 쓰기는 관리자 확인, 중복·경합·자정·시간대 변경 검증 유지.

## 아직 구현하지 않음

메모 저장/검색, 알람 스케줄러·예약 실행·푸시, UI 없는 자동 변경, LLM에 임의 shell/SQL/URL 도구 노출, MCP 서버, 긴 대화 기억, 여러 작업 묶음, 원음을 근거로 하는 새 ASR 보정, 반복 생성의 스트리밍 조기 취소. 일반 대화의 환각을 완전히 검출하지 못합니다.
