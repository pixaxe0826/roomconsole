# Room Hub 0.1.1 — GitHub 통합본 검증 기록

검증일: **2026-09-17**. 원본 0.1.1 ZIP에서 구성한 단일 저장소를 이 환경에서 다시 검사했습니다. 과거 패키지의 보고서를 그대로 성공 기록으로 재사용하지 않았습니다.

## 실행 환경

- Linux 컨테이너, Python **3.13.5**.
- pytest **9.0.2**, Playwright **1.57.0**.
- Chromium **144.0.7559.96**.
- 테스트 데이터는 합성 데이터와 임시 DB입니다. 사용자의 실제 운영 데이터·키·음원은 사용하지 않았습니다.

이 작업에서는 기존 런타임 파일을 변경하지 않았습니다. 테스트·문서·패키징 도구만 정리했습니다. 완료 통신 모의 테스트는 시나리오마다 새 문서로 초기화하여 이전 타이머/이벤트/전역 상태가 섞이지 않도록 했습니다.

## 배포물 점검

- ZIP은 `room-hub/` 한 폴더 아래에 소스·문서·예시·검사만 배치하도록 생성합니다.
- 운영 `data/`, DB/WAL/SHM, 인증 키 파일, `.env`, 음원, 가상환경, `.git`, 원본 로그, 폰트 바이너리를 포함하지 않습니다.
- README의 세 이미지는 독립 데모의 가상 데이터 화면에서 새로 캡처했습니다.
- 독립 미리보기 두 HTML은 실제 web/widgets 소스에서 다시 생성했습니다.
- ZIP 무결성과 파일별 SHA-256은 생성 도구와 패키징 테스트에서 확인합니다. 체크섬은 디지털 서명이나 보안 감사의 대체가 아닙니다.

## 검증하지 않은 범위

실제 Windows/iPad Safari의 end-to-end 사용, 원격 GitHub Actions, Docker 이미지 빌드/운영, TrueNAS 설치·ACL, 실제 Alexa/Google 연결, 외부 날씨 API 및 장시간 상시 운용은 이 통합 작업에서 직접 검증하지 않았습니다.

CI 정의는 이러한 일부 환경을 앞으로 실행할 수 있게 준비한 것이며, 이미 GitHub에서 성공했다고 표시하지 않습니다. 로컬 Chromium은 실제 서버로 탐색하는 브라우저 E2E 대신 독립 HTML을 렌더링합니다. 통신 모의 검사와 실제 HTTP 검사는 서로 다른 검사입니다.
