# 개발 후보 — 미구현

[문서 홈](../README.md)

아래 항목은 조사·추천 단계의 후보이며 일정·구현 승인이 확정된 기능 목록이 아닙니다. 현재 앱에는 기본 위젯 clock/weather/todos/calendar/note만 포함됩니다.

| 후보 | 의도 | 필요한 작업 |
|---|---|---|
| 집중·생활 타이머 | 집중/휴식, 명명한 여러 타이머 | 서버 종료 시각·일시정지 상태, 재시작 후 만료 처리, 제어 권한 |
| 다음 일정·D-day | 가까운 시간 지정 작업·중요한 날짜 | 시간 없는 작업과 마감 구분, 기존 작업 참조 |
| 서버·갱신 상태 | 마지막 수신과 기능별 상태 | 클라이언트 heartbeat 판정, 서버 진단, 민감 정보 비표시 |
| 실내 환경 | 실제 온습도·센서 이력 | 센서·수집 경로, 갱신 시각·오래된 데이터 표시 |
| 방 모드 | 집중·휴식·외출·취침 프리셋 | 관리자 허용 동작, 부분 실패 표시, 실제 장치 연동 |
| 스마트팜 | 관수 기록·센서·물통·팬·LED | 별도 제어기 안전장치, 중복 명령 방지, 측정과 기록 구분 |
| 음악 제어 | 곡 정보·재생/일시정지 | 실제 지원되는 플레이어·API, 서버 측 토큰 저장 |
| 여러 대시보드 | 생활 화면과 방 관리 화면 분리 | 저장 모델, 이동 UI, 기존 배치 마이그레이션 |
| 상시 운용 강화 | 서버 없이 재열기·세션 갱신 | 오프라인 범위·HTTPS·캐시·충돌·장기 인증 설계 |
| 실제 음성 연동 | Alexa/Google 또는 자체 입력기 | 제공자 어댑터·인증, STT, 실행 전 권한·검토 정책 |

표시만 하는 위젯은 폴더 추가와 서버 데이터 API를 활용할 수 있습니다. 반면 지속 상태·제어·권한이 필요한 위젯은 서버 구현이 함께 필요합니다. 위젯 폴더 하나를 설치하는 것만으로 미구현 서버 기능이 생기지는 않습니다.
