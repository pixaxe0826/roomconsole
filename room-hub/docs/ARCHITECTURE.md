# Room Hub 0.1.1 — 구조와 경계

## 구성

```text
[관리자 브라우저 /manager] ── HTTP 쓰기 ──┐
                                       ▼
[향후 음성 어댑터] ── 입력 전용 API ── [FastAPI 서버 + SQLite]
                                       │
                      상태 변경 / WebSocket invalidate
                                       ▼
                           [iPad Safari /client]
                    GET snapshot → 로컬 렌더링 / 날짜 조회
                    PATCH completion → 해당 회차 완료 체크
```

한 서버·한 작업 공간. 여러 표시 기기는 같은 영구 배치를 공유합니다. 일시적인 확대·선택 날짜는 특정 기기만 원격 제어할 수 있습니다. 기기별 영구 프로필은 이 버전의 기능이 아닙니다.

서버는 Python 3.11+, FastAPI, Uvicorn, SQLite입니다. 프런트는 빌드 단계 없는 HTML/CSS/JavaScript이며 외부 CDN이나 폰트 다운로드가 필요 없습니다. 하나의 작업자 프로세스를 사용해야 합니다. 연결 목록이 프로세스 메모리에 있으므로 `workers > 1`이나 여러 컨테이너로 수평 확장하면 현재 동기화 모델이 유지되지 않습니다.

## 상태와 실시간 처리

1. 관리자 변경 또는 표시 기기의 완료 전용 변경을 SQLite에 저장하고 전역 revision을 올립니다.
2. `/ws/display`, `/ws/manager`에 invalidate를 보냅니다.
3. 클라이언트는 인증된 `/api/state`에서 최신 스냅샷을 조회합니다.
4. 현재 선택 날짜와 확대 화면을 가능한 한 유지합니다.

WebSocket 끊김 시 최대 15초 간격의 재연결을 시도하며, 30초 주기 조회도 제공합니다. ping은 20초, 서버 수신 타임아웃은 65초입니다. 현재 열린 화면은 마지막 데이터를 남기고 연결 경고를 표시합니다. 오프라인에서 페이지를 새로 열거나 재시작하는 완전 오프라인 PWA는 아닙니다.

시계는 서버 시각과 브라우저 시각의 차이를 기준으로 매초 갱신합니다. 시간대는 IANA 이름으로 관리합니다. 자정에 오늘 날짜와 오늘을 따라가던 할 일 화면을 갱신합니다. 사용자가 과거·미래 날짜를 명시적으로 선택한 경우 선택을 유지합니다.

날씨는 서버만 Open-Meteo API에 요청합니다. 기본 15분, 5~120분 설정 가능. API의 제공 시각과 조회 시각, 최신 관측 시각은 같은 개념이 아닙니다. 실패 시 최근 데이터를 보관하고 오류를 표시합니다. 위치가 변경되면 이전 위치의 캐시는 지웁니다. 최초 실행은 위치 미설정이며 임의 도시를 사용자의 위치로 가정하지 않습니다.

## 데이터 모델

- tasks: 날짜별 독립 회차, 완료, 시간, 분류, 우선순위, 메모, version.
- series: 생성 당시 반복 규칙과 원본 요청. `series_id`로 회차 연결.
- kv: 설정, 배치, 날씨, revision, 위젯별 서버 데이터.
- devices / sessions / pairs: 표시 기기, 해시된 세션, 일회용 연결 코드.
- voice: 음성·텍스트 수신 이벤트, 중복 키, 원본 위치, 전사·검토 상태.
- audit: 최근 1,000건의 주요 변경 이력.

SQLite WAL과 트랜잭션을 사용합니다. 작업 수정과 레이아웃에는 버전 충돌 검사(409)가 있습니다. 삭제 시 버전을 보내면 동일한 검사를 합니다. 할 일·음성 처리·배치 UI는 단일 사용자/소규모 로컬 사용을 목표로 합니다.

반복은 달력 날짜로 계산하고 종료일을 포함해 실제 회차를 생성합니다. 주 단위 간격의 기준은 시작일이 포함된 월요일 시작 주입니다. 월간은 원래 일자를 유지하되 짧은 달은 말일로 보정합니다. 1월 31일 → 2월 말일 → 3월 31일. 각 회차만 수정하거나, 선택 회차·그 이후·전체 반복을 삭제할 수 있습니다. 기존 시리즈 규칙 전체를 편집하는 기능은 없으므로 필요할 때 이후 회차를 지우고 새 규칙으로 생성합니다. 생성 범위 최대 약 5년(1,827일), 전체 작업 최대 10,000개입니다.

## 완료 입력과 주간 탐색 (0.1.1)

날짜 선택은 기기 로컬 화면 상태이며, 일~토 7칸을 표시합니다. 화살표는 선택 날짜에 ±7일을 더하고
달력 표시 월을 함께 맞춥니다. 오늘 버튼은 서버의 오늘로 돌아갑니다. 기존 반복 규칙과 DB 날짜는 그대로입니다.

표시 쿠키는 `/api/tasks/{id}/completion`만 추가로 쓸 수 있습니다. 요청의 version과 완료 boolean을 검증하고
SQLite `BEGIN IMMEDIATE` 안에서 단일 회차를 읽고 검사한 뒤 업데이트합니다. 다른 값·API 권한은 열지 않습니다.
클라이언트는 완료를 낙관적으로 확정하지 않으며, 응답 전 중복 클릭 차단, 12초 요청 중단, 버전 충돌과 삭제 안내,
이전 스냅샷의 역전 방지, 현재 조회 날짜·확대 화면·스크롤 유지를 포함합니다.

## 보안 경계

관리자 키와 입력 키는 서로 다릅니다. 환경변수를 지정하지 않으면 서버가 무작위로 생성하여 data/에 저장합니다. 관리자 로그인 세션 12시간, 표시 기기 세션 30일, 연결 코드 10분/1회입니다. 표시 기기는 입력 키나 관리자 키를 알 필요가 없습니다. 관리자 세션은 HttpOnly/SameSite Strict 쿠키입니다. 기기 연결 취소는 세션 폐기와 WebSocket 종료를 수행합니다.

쿠키 기반 변경 요청은 `X-Room-Request: 1`을 사용하며 다른 Origin은 거부합니다. CORS 전체 허용을 하지 않습니다. 실제 HTTPS 환경에서만 `HUB_SECURE_COOKIE=true`로 설정합니다. 기본 HTTP는 암호화되지 않으므로 신뢰 가능한 로컬망 전용입니다. 이 구현을 검증된 인터넷 공개용 인증 게이트웨이로 취급하면 안 됩니다. 역방향 프록시/DNS rebinding/외부 접근 정책 등은 배포 환경에서 별도로 검토해야 합니다.

서버의 전체 HTTP body 제한 11MB, 개별 업로드 10MB. 오디오 MIME 화이트리스트와 텍스트 UTF-8 검사를 하며, 오디오는 서버가 실행하거나 디코딩하지 않고 불투명 `.bin`으로 저장합니다. MIME만으로 정상 음원인지 검증한 것은 아닙니다. 원본 파일은 명시적으로 삭제할 때까지 보관되며 자동 보관 기간 정책은 아직 없습니다.

기본 위젯은 문자열을 HTML escape 합니다. 확장 위젯 코드는 신뢰된 동일 출처 JavaScript입니다. 보안 샌드박스가 아니며 관리자 미리보기에서도 실행됩니다. 타인이 제공한 코드를 검토 없이 설치하지 마세요. widgets/는 정적 제공 경로이므로 비밀 키나 비공개 자료를 넣지 마세요. 서버 Python 코드를 폴더 추가만으로 자동 실행하지 않습니다.

## 이 버전에 포함되지 않는 것

실제 Alexa/Google Home 연결, STT, 자연어 의미 분석, 자동 실행, iCloud/Apple 캘린더·미리 알림 동기화, 외부 서비스 로그인, iPad 화면 강제 켜기, 네이티브 키오스크 제어, 서버 없는 iPad 단독 실행, 푸시 알림, 사용자별 계정 체계, 반복 규칙 전체 편집, 기기별 영구 레이아웃, 서버 클러스터. 이러한 경계는 버그가 아니라 초기 버전의 명시적인 범위입니다.
