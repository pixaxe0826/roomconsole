# 변경 이력

기능 버전과 저장소 정리를 구분합니다. 이 ZIP의 실행 기능 버전은 **0.1.1**입니다.

## 0.1.1 — 2026-09-17

### 변경

- 할 일의 날짜 줄을 일요일~토요일로 고정했습니다.
- 이전/다음 주와 오늘 버튼을 추가했습니다. 주 이동 시 선택 요일을 유지하고 달력의 월을 동기화합니다.
- iPad에서 해당 날짜 회차의 완료·완료 취소를 허용했습니다.
- 완료 전용 API, 서버 버전 충돌 검사, 중복 터치 차단과 연결 오류 처리를 추가했습니다.
- 관리자 미리보기의 크기 축소 수정과 렌더링 재진입 방어를 유지했습니다.

### GitHub 통합 정리 — 같은 기능 버전

- 기존 0.1.1 전체 소스를 기준으로 단일 저장소 구조를 구성했습니다. 런타임 파일과 런타임 의존성은 원본 0.1.1에서 변경하지 않았습니다.
- README, 설치·운영·백업·업로드·기여·보안·미구현 로드맵 문서를 정리했습니다.
- 패치별 ZIP과 중복 안내, 오래된 생성 로그를 저장소에서 제거했습니다.
- 테스트 결과를 `artifacts/`로 분리하고 텍스트 생성 도구에 UTF-8 인코딩을 명시했습니다.
- 완료 통신 모의 테스트의 문서를 시나리오마다 초기화하여 이전 타이머·전역 상태가 섞이지 않도록 했습니다.
- 안전한 소스 ZIP 생성, 상대 문서 링크·버전·민감 파일 검사, 패키징 테스트를 추가했습니다.
- GitHub Actions CI, 수동 ZIP 생성 워크플로, 이슈·PR 템플릿과 Dependabot 설정을 추가했습니다.
- 새 위젯 후보는 로드맵으로만 남겼습니다. 타이머 등의 기능이 추가된 버전이 아닙니다.

## 0.1.0 — 2026-09-17

### 초기 기능

- iPad 클라이언트, 관리자, 시계·날씨·할 일·달력·메모 위젯.
- SQLite 저장, 반복 일정, 격자 레이아웃, 연결 링크·QR, 원격 제어.
- 텍스트·음성 파일 수신함과 수동 검토.
- Python·Docker 실행과 독립 HTML 미리보기.

### 미리보기 수정

`ResizeObserver`가 관찰 대상의 높이를 반복 수정하며 폭이 축소되는 문제를 해결했습니다.
미리보기 박스는 CSS로 크기를 결정하고, JavaScript는 고정 1194×834 iframe의 배율만 변경합니다.
