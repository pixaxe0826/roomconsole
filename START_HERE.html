03 · 실제로 사용하기

  1. Windows: START_WINDOWS.bat 실행. Linux/macOS: ./start.sh 실행. Python 3.11 이상이 필요합니다.
  2. 또는 Docker 환경에서 아래 명령으로 컨테이너를 시작합니다.
docker compose up -d --build
docker compose logs room-hub
  1. 콘솔의 관리자 키로 http://서버IP:8088/manager에 로그인합니다.
  2. 관리자 표시 기기에서 연결 링크를 만들고, 같은 Wi-Fi의 iPad Safari에서 엽니다.
  3. 날씨 위치·할 일·위젯 배치는 관리자에서 설정합니다. 실제 서버에는 예시 일정이 들어 있지 않습니다.

자세한 실행·TrueNAS 경로·백업·보안 안내: README.md

주의: 음성 입력은 수신함까지 준비되었습니다. 실제 Alexa/Google 연동·전사·자동 실행은 아직 연결되지 않았습니다. 기본 HTTP는 로컬망 전용이며 인터넷에 직접 공개하지 마세요.
